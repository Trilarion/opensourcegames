# isleforge

- Home: https://goodoldgames.dev/en/page/anno-1503
- Media: https://en.wikipedia.org/wiki/Anno_1503
- Inspiration: Anno 1503
- State: beta
- Download: https://goodoldgames.dev/media/isleforge-rc14-x86_64.tar.gz (Linux x86_64 RC14 bundle, includes GPL-3.0-or-later C11 source), https://goodoldgames.dev/media/isleforge-rc14-arm64.tar.gz (Linux ARM64)
- Platform: Linux
- Keyword: strategy, remake, real-time, content commercial, engine recreation, original required (Anno 1503 A.D.)
- Code language: C
- Code license: GPL-3.0
- Code dependency: SDL2
- Developer: Michael König-Weichhardt

Unofficial clean-room C11/SDL2 engine, public release candidate RC14 only. Requires a legally purchased copy of Anno 1503 A.D. Royal Edition. Building and sailing work; campaign events, walkers, Bink video and multiplayer are not done yet. Very new, so bugs can happen. Bug tracker: https://goodoldgames.dev/en/social.
