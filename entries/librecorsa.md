# LibreCorsa

- Home: https://librecorsa.org/
- Inspiration: Assetto Corsa
- State: beta
- Play: https://librecorsa.org/
- Platform: Web
- Keyword: simulation, 3D, racing, multiplayer online
- Code repository: https://github.com/KhazP/librecorsa.git
- Code language: TypeScript
- Code license: MIT
- Code dependency: Three.js, Next.js, WebRTC
- Assets license: CC-BY-NC-SA-4.0 (RISE Motordrome circuit, tyre artwork), CC-BY-4.0 (2026 prototype car, foliage)
- Developer: Alp Yalay

Racing sim that runs in the browser. Fixed 500 Hz vehicle physics (6-DOF rigid body with double-wishbone suspension, Pacejka tyres with temperature and wear), wet weather, AI races and peer-to-peer WebRTC multiplayer.

- Build system: npm
