# OpenMW Web

- Home: https://morrowind.virtastic.app/
- Inspiration: The Elder Scrolls III: Morrowind
- State: mature
- Play: https://morrowind.virtastic.app/
- Platform: Web
- Keyword: game engine, remake, role playing, content commercial, original required (Morrowind)
- Code repository: https://github.com/Virtastic/openmw-web.git
- Code language: C++
- Code license: GPL-3.0
- Developer: Virtastic

The [OpenMW](openmw.md) engine cross-compiled to WebAssembly with Emscripten. Morrowind runs
client-side in a Chromium browser at 60fps with no installation. Ships a free example world;
players can load their own legally-owned game data, which is read locally from disk and never
uploaded.

## Building

- Build system: CMake
