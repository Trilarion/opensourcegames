# Standard of Iron

- Home: https://github.com/djeada/Standard-of-Iron
- State: beta
- Download: https://github.com/djeada/Standard-of-Iron/releases
- Platform: Windows, Linux, macOS
- Keyword: strategy, content open, single-player, real-time
- Code repository: https://github.com/djeada/Standard-of-Iron.git
- Code language: C++
- Code license: MIT
- Code dependency: Qt 6, OpenGL 3.3
- Developer: Adam Djellouli

Single-player real-time strategy game set during an alternate Second Punic War. The player commands army formations, can directly control a battlefield commander, manages a settlement economy, and plays campaign, tutorial, and skirmish scenarios.
