# Trick or Take

- Home: https://trickortake.com
- State: beta
- Play: https://trickortake.com
- Platform: Web
- Keyword: arcade, action, multiplayer, real-time voice chat, halloween
- Code repository: https://github.com/zicojiao/trick-or-take.git
- Code language: TypeScript, JavaScript
- Code license: MIT
- Code dependency: Next.js, React, Tailwind CSS, Agora RTC SDK
- Developer: Zico Jiao

A fast-paced multiplayer Halloween candy heist web game where players steal candy in 60 seconds with real-time Agora voice chat. Sneak around, grab pumpkins, but watch out for roaming ghosts — get caught and all your candy drops.
